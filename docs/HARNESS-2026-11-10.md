## 1. 궁극적 목표

**AI 에이전트가 POSIX 에뮬레이터(MSYS, Cygwin, WSL) 대신 쓸 수 있는 계층.**
에이전트가 Bash 도구로 던지는 명령이 Windows 네이티브에서 GNU/Linux와 같은 결과를 내야 합니다.

원칙:
- GNU/Linux와 같은 일을 같은 방식으로 한다. Windows가 할 수 없는 것만 적응한다 (적응한 것은 문서에 적는다).
- 에이전트는 학습 데이터에 있는 GNU 출력을 기대하므로, 출력 바이트와 종료 코드를 GNU와 맞춘다 (`test/gnu/<도구>.sh`).
- 가상 루트(`/c` = `C:\`)로 POSIX 경로를 쓴다.

## 2. 현재 상태 (2026-11-10)

- 도구 109개, 테스트 프로그램 100개, `nmake test` / `asan` / `check-registry` / GNU 비교 모두 통과. GNU 비교가 없는 도구 16개.

- 쉘 항목: Ctrl+Z 작업 멈추기, `trap` 의 다른 신호.
- README의 "43개의 명령", "38개 테스트 프로그램"은 오래된 숫자.
