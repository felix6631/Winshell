작업 중에 다시 읽으며 진행하기 위한 문서입니다. 작업이 끝날 때마다 체크박스와 "진행 기록"을 갱신합니다.

## 1. 궁극적 목표

**AI 에이전트가 POSIX 에뮬레이터(MSYS, Cygwin, WSL) 대신 쓸 수 있는 계층.**
에이전트가 Bash 도구로 던지는 명령이 Windows 네이티브에서 GNU/Linux와 같은 결과를 내야 합니다.

원칙:
- GNU/Linux와 같은 일을 같은 방식으로 한다. Windows가 할 수 없는 것만 적응한다 (적응한 것은 문서에 적는다).
- 에이전트는 학습 데이터에 있는 GNU 출력을 기대하므로, 출력 바이트와 종료 코드를 GNU와 맞춘다 (`test/gnu/<도구>.sh`).
- 가상 루트(`/c` = `C:\`)로 POSIX 경로를 쓴다.

### 3.2 빠진 명령
- [x] `timeout`: `-s -k --preserve-status --foreground -v`, 종료 코드 124/125/126/127/137, 시간 접미사 `s m h d`. Windows 적응: 시그널 대신 `kill`과 같은 방식(TERM은 창 닫기 후 종료, KILL은 즉시 종료).
- [x] `basenc`: `--base64 --base64url --base32 --base32hex --base16 --base2msbf --base2lsbf --z85 -d -w -i`. `base32`/`base64`와 `common/basecode` 공유.
- [x] `stty` 최소: `size`, `-a`/`-g`의 읽기, `columns`/`rows`. 나머지는 GNU와 같은 오류로 거절하고 문서에 적는다.
- 제외 명령(`chcon`, `chroot`, `runcon`)은 README의 제외 목록에 이유를 유지한다.

### 3.3 쉘 호환성 검증 (가장 큰 위험)
- [x] 에이전트가 자주 쓰는 패턴 목록을 만든다: 파이프, `&&`/`||`/`;`, `$(...)`, 백틱, heredoc(`<<`, `<<-`, `<<'EOF'`), `set -e/-u/-o pipefail`, `for`/`while`/`case`/`if`, 함수, `trap`, 프로세스 치환, 리다이렉션(`2>&1`, `&>`, `>>`), 글롭과 중괄호 확장, `$'...'`, `${var:-}` 류 확장, `export`, `read`, `getopts`, `[[ ]]`.
- [x] MSYS bash와 출력·종료 코드를 비교하는 스크립트를 만든다: `bash test/shell_compare.sh` (케이스는 `test/shell/cases.txt`, `SHELL_ONLY=이름`, `SHELL_VERBOSE=1`).
- [ ] 차이는 고치거나, 고칠 수 없으면 문서화한다. 첫 실행(2026-11-16): 121개 케이스 중 52개가 다르다. 원인별로 묶으면 (많은 순):
  1. (2026-11-16 해결: `set -e -u -o pipefail --`, `/dev/null`, `!` 부정; 121개 중 41개가 남음) `set` 내장 명령이 없다: `set -e`, `set -u`, `set -o pipefail`, `set -x`, `set -- args` (11개 케이스). 에이전트 스크립트 첫 줄이라 최우선.
  2. here-string `<<<`, 프로세스 치환 `<(...)`, `exec 3>` 같은 fd 리다이렉션, `&>` (약 12개).
  3. `/dev/null` 이 열리지 않는다 (8개). 에이전트 명령의 `2>/dev/null` 때문에 최우선. `grep /dev/null` 도 같은 원인.
  4. `!` 부정 (5개), `[[ ]]` (4개), `declare`/`readonly`/`let`/`type`/`command -v`/`getopts`/`eval` 같은 내장 명령 (약 12개).
  5. here document 가 일부 형태에서 실패 (`<<-`, 따옴표 붙은 구분자, 함수 안, `;` 뒤의 둘째 heredoc).
  6. `$'...'` 와 `\` 이스케이프, `printf %q`, `${v^^}` 류 대소문자 변환, `${v/%x/y}`, `${!name}`, 배열과 연관 배열.
  7. 그 밖: `read` 가 줄바꿈 없는 마지막 줄을 못 읽음, 파이프 안 `read` 가 부모 변수를 바꿈(서브쉘 격리), `return` in source, `case ;;&`, `for ((;;))` 와 중괄호 범위, `$*` 와 IFS.
  각 항목을 고칠 때마다 `bash test/shell_compare.sh` 의 차이 수를 줄이고, 줄인 케이스는 `test/shell_*_test.c` 에도 넣는다.
- [ ] 쉘 로드맵 항목(Ctrl+Z, `trap` 신호)은 에이전트 사용에 영향이 있는지 보고 우선순위를 정한다.
